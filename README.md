# Iconic Locations of the Basque Country 🗺️

An illustrated guide to 24 iconic places across Euskal Herria — Bizkaia, Gipuzkoa, Araba, Navarre
and Iparralde (the French Basque Country) — with photos, descriptions and a province filter.

## Run locally
Open `index.html`, or:

```bash
python3 -m http.server 8000
```

## Build
`index.html` is generated by `build.py` from `meta.json` (image licences/paths):

```bash
python3 build.py
```

## Images
Photographs via Wikimedia Commons under their respective licences; full credits are in the
collapsible section at the bottom of the page.
