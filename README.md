# Iconic Locations of the Basque Country 🗺️

A multilingual illustrated guide to 24 iconic places across Euskal Herria — Bizkaia, Gipuzkoa,
Araba, Navarre and Iparralde (the French Basque Country).

## Languages
The site is available in four languages, switchable from the top-right of every page:

| Page | Language |
|------|----------|
| `index.html` | English |
| `es.html`    | Español |
| `eu.html`    | Euskara |
| `fr.html`    | Français |

## Features
- 24 locations, each with a photo, Basque/alternate name, description and tags
- Interactive province filter (All / Bizkaia / Gipuzkoa / Araba / Navarre / Iparralde)
- Illustrated introduction to the region and a facts strip
- Image credits & licences in a collapsible section

## Build
`index.html`, `es.html`, `eu.html` and `fr.html` are generated by `build.py` from `meta.json`
(image data) plus the translations embedded in the script:

```bash
python3 build.py
```

## Run locally
```bash
python3 -m http.server 8000
```
