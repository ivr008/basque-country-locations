# Iconic Locations of the Basque Country 🗺️

A single-page, multilingual illustrated guide to 24 iconic places across Euskal Herria — Bizkaia,
Gipuzkoa, Araba, Navarre and Iparralde (the French Basque Country).

## Languages
One page, four languages, switched **in place** from the top-right control:
**English · Español · Euskara · Français**. The chosen language is remembered
(`localStorage`) and the page auto-selects your browser language on first visit.

## Features
- 24 locations, each with a photo, Basque/alternate name, description and tags
- Interactive province filter (All / Bizkaia / Gipuzkoa / Araba / Navarre / Iparralde)
- Illustrated introduction to the region and a facts strip
- Image credits & licences in a collapsible section

## Build
`index.html` is generated by `build.py`, which embeds all four translations plus the image data
from `meta.json`:

```bash
python3 build.py
```

## Run locally
```bash
python3 -m http.server 8000
```
